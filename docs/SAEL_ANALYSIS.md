# Разбор sael.net/interior и что перенесено в VSEMDOM

## Доступность

`https://sael.net/interior/` открывается из среды: HTTP 200, одна HTML-страница 232 727 байт со встроенными
модулями (основной — ≈196 КБ JavaScript). Страница работает в headless Chromium (программный WebGL), код
прочитан полностью. Адрес `www.sael.net` прокси среды не пропускает — он не нужен. Код страницы в репозиторий
не копировался: ниже — описание приёмов и то, как они реализованы у нас собственным кодом.

## Что это

«Set the Mood» — мудборд, который сразу собирает комнату: разрезанная квартира на подиуме (гостиная, обеденный
угол, спальня, кабинет). Образцы (дерево, камень, ткань, краска) перетаскиваются на поверхности, мебель
двигается с шагом 10 см с прилипанием к стенам и без пересечений, солнце тянется по небу (утро 07:36,
день 12:48, вечер 18:30, ночь 22:12), есть панель настроек рендера.

## Как устроено (по коду)

| Подсистема | Приём |
|---|---|
| Рендерер | three.js r183 (та же версия, что у нас), ACES, экспозиция × таблица времени суток; объект качества `RT` (pixelRatio, MSAA 2/4 по плотности пикселей, SMAA, тени 2048, насыщенность 1,16, отражения 0,5…); адаптивный pixel ratio |
| Постобработка | HalfFloat-цель с MSAA, защита от NaN/Inf и ограничение яркости 6 в проходе сцены; GTAO и bloom в половинном разрешении; собственный DOF; SMAA после OutputPass |
| Тени | `shadowMap.autoUpdate = false`, флаг «грязной» карты: тени пересчитываются только при изменении сцены |
| Свет | студийное окружение PMREM с софтбоксами; солнце + заполняющий + контровой; таблица ключевых кадров времени суток (солнце, цвета, экспозиция, окружение, порог bloom, лампы); лунный свет ночью |
| Дешёвые точечные источники | 10 «фейковых» ламп в видовых координатах: из пула выбираются самые заметные (интенсивность × радиус / (1 + 0,01·d²)), вклад добавляется после `lights_fragment_end` через `material.diffuseContribution`, окно `(1 − d²/r²)²` |
| Цвет | насыщенность `uSat` в шейдере каждого материала перед `opaque_fragment` |
| Материалы | процедурные тайлы 512², запекаемые на GPU (цвет+шероховатость, нормаль+высота): дерево, бетон, терраццо, травертин, мрамор, сланец, лён, букле, бархат, кожа, трикотаж, войлок, краска, известь; шейдер раскладки (доска, плитка, опалубка, ковёр) через `textureGrad`; sheen и clearcoat |
| Модели | мягкая мебель из «надутых» коробок (подушка сиденья с куполом, подушка с защипом к краям, `mergeVertices` + сглаженные нормали); вазы — тела вращения; листья с изгибом и сгибом по жилке, жилка — цветом вершин; ряды книг; лампы со светящимися абажурами; свеча; картины по палитре; полупрозрачные шторы с синусоидальными складками |
| Атмосфера | лучи солнца в окнах: аддитивная призма от проёма + пыль (точки) в координатах призмы; планарное отражение пола |
| Запуск | `compileAsync` — прогрев шейдеров до первого кадра |

## Сравнение

| Аспект | sael.net | VSEMDOM до разбора | VSEMDOM сейчас |
|---|---|---|---|
| Сглаживание | MSAA 2/4 + SMAA | только SMAA | MSAA 4× на видеокарте + SMAA (на программном WebGL и в облегчённом качестве — SMAA) |
| Тени | по требованию | каждый кадр | по требованию: камера и огонь карту не трогают |
| Локальный свет | 10 фейковых ламп | 3 настоящих PointLight фасада | + пул до 10 дешёвых источников: костёр (мерцает), угли мангала, гирлянда, 5 столбиков; газон, трава, камень, дерево — все уличные материалы |
| Цвет кадра | насыщенность в каждом материале | ACES без коррекции | один проход после тонального отображения: насыщенность 1,08, мягкий контраст, виньетка |
| Ночь | луна (свет) | синий заполняющий свет | луна: холодный направленный свет с мягкими тенями + диск луны на небе |
| Лучи в окнах | призма + пыль | нет | призма от проёма до солнечного пятна на полу, мягкие края, затухание (прогулка) |
| Подушки | защип / купол | скруглённые коробки («колбаски») | защип на кровати и диване, купол на подушках скамеек |
| Растения и декор | листья, вазы, книги, лампы | чаша и две «книги»-коробки | фикус, куст, базилик, эвкалипт из листьев; вазы, горшки, корзина, книги с блоком страниц, лампа со светящимся абажуром, свеча |
| Шторы | полупрозрачные | нет | плотный лён со складками и карнизом во всех жилых комнатах |
| Материалы | GPU-запекание | карты Blender | карты Blender (+ гравий, плитняк, торец полена, береста) |

## Перенесено — с изменениями под наш проект

1. **Дешёвые точечные источники** (`dist/point-lights.js`). В отличие от sael — мировые координаты, затухание
   «обратный квадрат с мягким ядром × окно по радиусу» (у sael — только окно), мерцание пламени суммой
   несоизмеримых синусов, униформа числа активных источников: днём цикл в шейдере не выполняется. Патч
   цепляется к уже существующему `onBeforeCompile` (газон, трава, угли) и даёт свой ключ программы.
2. **Тени по требованию** (`app.js`): `invalidate()` помечает карту, движение камеры — `invalidateView()`;
   прогулка и редактор помечают карту, когда двигают двери и мебель; превью освещения пересчитывают её сами.
   Теневая камера солнца плотно подбирается под дом и мангальную зону (`fitShadow`).
3. **MSAA** — на видеокарте; программный WebGL определяется по имени рендерера.
4. **Цветокоррекция** — одним проходом вместо правки каждого материала: дешевле и одинаково для всех.
5. **Луна** — тот же источник, что и солнце: после заката он поворачивается на высоту 38° против азимута
   солнца, свет холодный 0,34 с мягкими тенями.
6. **Лучи солнца** (`dist/sun-beams.js`) — дальний край призмы лежит на полу, там, где солнечное пятно; пыль
   не перенесена (нужна непрерывная перерисовка).
7. **Мягкие подушки, листья, тела вращения, книги, лампа, шторы** (`dist/decor.js`, `dist/curtains.js`) —
   декор привязан к мебели и не выходит за габарит каталога (проверка «Габариты моделей мебели совпадают
   с каталогом» продолжает проходить).

## Сделано сверх sael (по заданию)

- **Мангальная зона с костром** (`dist/bbq-zone.js`): площадка из природного плитняка — степенная диаграмма
  Вороного (крупные и мелкие плиты, швы 12–22 мм, неровные скруглённые кромки, фаска, уклоны, свой тон
  каждой плиты); кострище из колотого камня с копотью; берёзовые дрова шалашом с обугленным низом и
  тлеющими трещинами; зола и угли; живое пламя (5 языков, турбулентность fbm, HDR-цвет, синее основание);
  искры; дым, подсвеченный огнём ночью; ореол; мангал с углями, шампурами и светящимися поддувалами;
  скамьи с подушками и пледом в клетку; пни; поленница с колотыми берёзовыми дровами; гирлянда на столбах
  с ореолами ламп. Режим костра хранится в проекте и ссылке.
- **Дорожки**: гравийная дорожка от ступеней к зоне, площадка у ступеней, отмостка вокруг дома, стальной
  бордюр, ещё два столбика-светильника.
- **Водостоки**: желоба, крюки, воронки, трубы с коленами и хомутами.
- **Фактуры Blender**: гравий (два слоя окатанных зёрен), плитняк (слоистость, железистые пятна, лишайник),
  торец полена (кольца, ядро, трещины, кора), береста (чечевички, чёрные трещины).

## Не перенесено — и почему

| Приём | Причина |
|---|---|
| Планарное отражение пола | полы матовые (доска, плитка); второй проход сцены удвоил бы стоимость кадра; отражения даёт окружение PMREM |
| Студийное окружение с софтбоксами | у нас реальный участок: окружение снимается кубической камерой с неба и рельефа |
| GPU-запекание материалов | карты делаются в Blender — воспроизводимо и работает в автономном HTML без сети |
| Таблица времени суток | солнце рассчитывается по NOAA для координат, даты и времени — таблица не нужна |
| Пыль в лучах, `compileAsync` | пыль требует непрерывного рендера; прогрев не компилирует скрытые (дневные) шейдеры огня |
| GTAO/bloom в половинном разрешении | bloom по умолчанию выключен; GTAO уже масштабируется вместе с pixel ratio |
