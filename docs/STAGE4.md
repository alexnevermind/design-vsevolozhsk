### Автономный HTML

Один файл со всем внутри: код приложения, стили, Three.js, данные участка и построек, карты материалов,
модель. Работает с диска (`file://`) без сети: участок, фасады «Доска» / «Штукатурка и кирпич», солнце и
время, «Внутри» с разрезами и перестановкой мебели, прогулка снаружи и внутри, кадр PNG 1800 × 1120, ссылка
с состоянием. В архиве — README, лицензии Three.js, контрольные суммы SHA-256. Дом базы также пересобран
(`offline/base/VSEMDOM.html`, `artifacts/VSEMDOM-local.zip`).

### Файл Blender

Сцена выгружена из работающего приложения (та же геометрия) и разложена по коллекциям:

- **Постройки** — гостевой дом-баня, гриль-дом, навес с хоз.блоком: стены, проёмы, окна и двери, кровли,
  водостоки, интерьеры (обшивка, полы, потолки по скатам, перегородки, двери, лестница, ограждения);
- **Мебель · по листам** — исходная расстановка;
- **Фасад 1 · доска** (включена) и **Фасад 2 · штукатурка и кирпич** (выключена) — переключение вариантов
  фасада галочками коллекций;
- **Рельеф и газон**, **Благоустройство** (забор, ворота, дорожки, отмостка, пруд, купель, спортплощадка,
  ЛОС, кострище, гриль-зона, кусты), **Очаг гриль-дома**, **Деревья по плану** (группа на дерево `tree_T01…`),
  **Фон · лес за забором**, **Фонари и столбики**, **Камеры** (13 видов приложения).

Две сцены с общими коллекциями: **«День · 21 июня 13:00»** (солнце для Всеволожска, небо Nishita) и
**«Ночь · 23:15»** (фонари у дверей, столбики, свет помещений, огонь). Рендер — Cycles, AgX. Карты упакованы
в файл. Пересборка: `npm run export:site`, затем `scripts/blender/make_site_blend.py [--render]`.

## Проверки

`npm run check:all` — всё по порядку, итог в `docs/CHECKS.md`:

- модульные тесты (`npm test`) — база и участок, в т. ч. прогулка внутри, лестница, мебель, состояние;
- согласованность данных базы и участка (`spec --check`, `site --check`);
- браузерная проверка участка (`site:check`) — постройки, виды, деревья, солнце, огонь, прогулка, ссылка, PNG,
  телефон, фасады, ночной свет, «Внутри», перенос мебели, прогулка внутри;
- браузерные маршруты дома базы (`browser:check`);
- сборка автономных версий и проверка без сети (`package:offline`, `offline:check`).

Решения этапа — `docs/ASSUMPTIONS.md`, раздел 10.
